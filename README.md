# 日本語文章作成ガイドライン

Version: 1.0.0

## 1. 基本方針

専門的な内容を、自然で平易な日本語で、具体的に説明する。

業務文書、マニュアル、仕様書、報告書、説明資料などでは、文書の正式さと表現の堅苦しさを混同しない。日本語を母語とする実務者が、同僚や関係者に業務を説明する際に使う言葉を基本とする。

以下の三つの基準を独立して確認する。文法的に正しい文章でも、堅すぎたり、説明が不十分だったりすることがある。

**共通の前提：** 意味、論理、専門的な正確さを維持する。用語の定義、数値、条件、対象範囲、因果関係、義務・推奨・許可などの区別を変えない。元の内容にない事実や手順を加えない。法令、契約書、技術仕様、既存の用語規約などで表現が定められている場合は、その要件を優先する。

## 2. 三つの品質基準

### ① 日本語の自然さ

意味が通じるかだけでなく、その場面で日本語として一般的な言い方になっているかを確認する。

- 名詞と動詞の組み合わせを確認し、物理的な動作を表す動詞を、慣用的でない対象に対して使わない。
- 英語の直訳調の表現や、読み手に通じにくい業界特有の言い回しを避ける。
- 単語を一律に禁止せず、文脈に応じて判断する。

| 見直したい表現 | 修正例 |
| --- | --- |
| 分析結果を意思決定に返す | 分析結果を意思決定に活かす |
| 〇〇を目標として置く | 〇〇を目標とする |
| 責任を管理者に置く | 管理者が責任を負う |
| 機能単位でタスクを切る | 機能ごとにタスクを分ける |
| 対象をここで切る | ここまでを対象とする |
| 対応範囲に線を引く | どこまで対応するかを決める |
| 知識を実務に落とす | 知識を実務に活用する |
| 判断を担当者に投げる | 担当者に判断を依頼する |
| 例外を別の処理に逃がす | 例外は別の方法で処理する |
| 施策の解像度を上げる | 施策の内容を具体的に決める |
| チーム間でアラインする | チーム間で認識を揃える |
| 読み手に対して明確さを提供する | 読み手が理解できるように説明する |

「話を戻す」「値を返す」「電源を切る」「x = 1 と置く」など、自然な用法や専門的な用法まで避ける必要はない。修正例は、想定する意味が一致する場合に使う。

### ② 表現の平易さ

意味が同じなら、普段の仕事で使う普通の言葉を選ぶ。真面目な文書でも、必要以上に堅い言葉を連続して使わない。

- 漢語や名詞が続く場合は、動詞を使った普通の文にできないかを考える。
- 回りくどい表現、重複、内容に見合わない強調を避ける。一文に条件や作業が多く含まれる場合は、必要に応じて文を分ける。
- 専門用語は、特定の概念を正確に表すために必要なら維持する。

| 見直したい表現 | 修正例 |
| --- | --- |
| 必要性を考慮する | 必要かどうかを考える |
| 対応方針を策定する | どのように対応するかを決める |
| 情報の収集を実施する | 情報を集める |
| 結果の確認を行う | 結果を確認する |
| 設定変更の要否を検討する | 設定を変更する必要があるかを考える |
| 調査目的との整合性を確認する | 調査目的に合っているかを確認する |
| 内容の精査を実施する | 内容を詳しく確認する |
| 対象の再設定を行う | 対象を設定し直す |
| 実施可否を判断する | 実施できるかどうかを判断する |
| 作業完了後の報告を必須とする | 作業が完了したら必ず報告する |
| 作業の完了をもって次工程へ移行する | 作業が完了したら次の工程に進む |
| 事前の確認が必要となる | 事前に確認する必要がある |
| 変更することが可能である | 変更できる |
| 適宜修正を施す | 必要に応じて修正する |
| 事前にあらかじめ確認する | 事前に確認する |

「考慮する」が判断材料に含めるという意味なら、「〇〇も判断材料にする」など、意味に合う表現を選ぶ。「統計的有意差」「標本誤差」などの専門用語は、堅いという理由だけで変更しない。

### ③ 説明の具体性

読み手が、何を考え、何を判断し、何をするのかを理解できるように書く。必要な説明を一つの抽象的な言葉で済ませない。

- 必要に応じて、誰が、何を、どのような条件で、どのように行うのかを記載する。
- 文章を短くすることより、読み手が内容を正確に理解できることを優先する。
- 具体的に書くために情報が不足している場合は、元の内容にない条件、手順、担当者などを勝手に追加しない。

次の例では、括弧内の内容が元の指示や業務上の条件に含まれることを前提とする。

| 見直したい表現 | 修正例 |
| --- | --- |
| 検討事項を示す | 検討すべき事項を洗い出し、報告書に記載しておく（洗い出しと記載が必要な場合） |
| 判断基準を明確化する | 何を基準に判断するのかを決めておく（基準を新たに決める場合） |
| 分析結果を踏まえて施策を検討する | 分析結果をもとに、どのような施策が有効かを考える（有効な施策を考える場合） |
| 分析手法の妥当性を確認する | 調査目的に合っているか、データが分析手法の前提条件を満たしているかを確認する（これらが確認項目の場合） |
| 必要に応じて対応する | 入力漏れがある場合は、入力した担当者に修正を依頼する（これが対応条件と方法の場合） |
| 関係者と連携する | 集計結果を営業担当者に共有し、報告書の内容を確認してもらう（この共有と確認が必要な場合） |
| 不備があれば修正する | 入力漏れや形式の誤りがある場合は修正する（不備がこの二つを指す場合） |

「示す」「担保する」「明確にする」などの表現も、具体的な意味が文脈から十分に伝わる場合はそのまま使ってよい。

## 3. 文章作成後の確認

完成した文章を以下の三つの観点から見直す。問題がある場合は、単語だけでなく文の構造も含めて修正する。

- [ ] 自然さ：その場面で日本語を母語とする実務者が普通に使う言葉の組み合わせになっているか。
- [ ] 平易さ：意味を変えずに、もっと普通の言葉で表現できないか。
- [ ] 具体性：読み手が何を考え、何をするのかを必要な程度まで理解できるか。

最後に、修正前後で意味、論理、専門的な正確さが変わっていないかを確認する。同じ概念を指す用語は文書内で統一し、異なる概念は区別する。

## 4. 改訂方針

実際の文章で違和感があった場合は、原文、文脈、該当する品質基準、修正例、修正理由を記録する。既存の三つの基準で説明できる問題については、新しいルールを設けず、事例として蓄積する。
